# Personal Assistant

A voice assistant project with wake word detection, voice activity detection, speech-to-text, LLM integration, text-to-speech, and basic tools.

## Features

- Wake word detection (using openwakeword)
- Voice activity detection (VAD) for utterance endpointing
- Speech-to-text (using faster-whisper locally or NVIDIA NIM)
- LLM integration (with NVIDIA NIM models)
- Text-to-speech (using Piper TTS locally or NVIDIA NIM)
- Basic tools: time, timers, notes, system

## Installation

1. Clone the repository.
2. Copy `.env.example` to `.env` and add your NVIDIA_API_KEY (if using NVIDIA NIM services).
3. Install dependencies:
   ```bash
   pip install -r voice-assistant/requirements.txt
   ```

## Usage

### Run the Voice Assistant

```bash
python voice-assistant/run.py
```

Use `--devices` flag to list audio devices.

Say your wake word (default: "hey jarvis") to activate.

### Explore the Codebase with Graphify

This project includes a knowledge graph generated by [graphify](https://github.com/safishamsi/graphifyy) to understand the codebase structure.

To regenerate the graph:

```bash
graphify .          # Full extraction (includes documents, may require API key for semantic extraction)
graphify . --code-only  # Code-only extraction (fast, no API key needed)
```

After extraction, run:

```bash
graphify cluster-only .  # Generate report and name communities
```

View the interactive graph:

```bash
start graphify-out/graph.html
```

Or open `graphify-out/graph.html` in your browser.

See `graphify-out/GRAPH_REPORT.md` for detailed analysis, including:
- God Nodes (core abstractions)
- Surprising Connections
- Suggested Questions for exploration

## Graphify Commands

- `graphify query "<question>"` - Ask a question about the codebase
- `graphify path "NodeA" "NodeB"` - Find shortest path between two concepts
- `graphify explain "NodeName"` - Get plain-language explanation of a node
- `graphify update .` - Incrementally update the graph after code changes
